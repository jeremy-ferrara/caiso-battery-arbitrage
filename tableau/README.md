# Tableau data sources

Generated by `python src/tableau_export.py` into `data/processed/` (not committed). Each file is one view's data source, already in long format.

- Strategy views cover only the matched comparison window (Aug 7 2023 - Aug 31 2026, 1,121 days per hub), so cumulative and average figures compare like with like.
- "Forecast-Driven" is the expanding-window ridge forecast.
- The persistence baseline and rolling-window variants appear only in `forecast_accuracy.csv`.

| File | Grain (one row per) | Fields |
|---|---|---|
| `daily_pnl.csv` | date x hub x strategy | Date, Hub, Strategy, Net Profit ($), Cumulative Net Profit ($) |
| `hourly_dispatch.csv` | Pacific hour x month x hub x strategy | Hour of Day (Pacific), Month, Hub, Strategy, Avg Charge (MW), Avg Discharge (MW) |
| `capture_rates.csv` | year x season x hub x strategy | Year, Season, Hub, Strategy, Days, Strategy Net Profit ($), Perfect Foresight Net Profit ($), Capture Rate (%) |
| `price_trends.csv` | month x hub | Month, Hub, Avg Daily Spread Max-Min ($/MWh), Avg Daily Spread Top 4 vs Bottom 4 Hours ($/MWh), Negative Price Hours, Hours in Month, Avg Day-Ahead Price ($/MWh) |
| `forecast_accuracy.csv` | period x hub x model x Pacific hour | Period, Hub, Model, Hour of Day (Pacific), MAE ($/MWh), RMSE ($/MWh), Bias Forecast minus Actual ($/MWh) |

Notes:

- **Capture rates.** Don't average `Capture Rate (%)` across rows. Re-aggregate as `SUM([Strategy Net Profit ($)]) / SUM([Perfect Foresight Net Profit ($)])` so pooled hubs, years, or seasons match the report. Capture rows exist for Rule-Based and Forecast-Driven only.
- **Seasons.** Seasons follow calendar months, and December counts toward its own calendar year's winter.
- **Hourly dispatch.** `Avg Charge (MW)` and `Avg Discharge (MW)` average over every day in the month, with idle hours counted as 0. On DST fall-back days the repeated hour is averaged in.
- **Forecast accuracy periods.** `forecast_accuracy.csv` has two periods: the full forecast period, and Jul 8 2024 onward, when every rolling window differs from the expanding model. MAE and RMSE are hourly; averaging them across hours is an approximation for RMSE.
- **Price trends.** `price_trends.csv` covers the full price history (Jul 2023 - Aug 2026), not the matched window.
